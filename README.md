# Cowswap xStocks Token List

Token list for xStocks tokenized assets, following the [Uniswap Token Lists](https://github.com/Uniswap/token-lists) specification.

> **Note:** To update the token list, run `npm run update`. This fetches live data from the xStocks API v2 `/assets` endpoint (`https://api.xstocks.fi/api/v2/public/assets`). Pass xStock tickers (e.g. `npm run update -- OURAx`) to include Private pre-IPO assets, or a local file path for offline overrides. See [Updating the Token List](#updating-the-token-list).

## Usage

Add the token list URL to your DEX or wallet that supports Uniswap Token Lists.

## Updating the Token List

Use the `update-tokenlist.js` script to update tokens:

```bash
# Fetch all public assets from the xStocks API
npm run update

# Also include specific assets by ticker, including Private (pre-IPO) ones
npm run update -- OURAx
npm run update -- OURAx FOOx BARx

# Offline override from a local JSON file (API-format assets or a flat token list)
node update-tokenlist.js <path-to-new-tokens.json>
```

The `--` passes the tickers through npm to the script.

### Including Private (pre-IPO) tokens

The public `/assets` endpoint only returns public assets. To list a token before its IPO goes live, pass its ticker. The script fetches it from `https://api.xstocks.fi/api/v2/public/assets/<ticker>`, authenticated with `BACKED_API_KEY`, and merges it into the list.

Put the API key in a `.env` file in the repo root. `.env` is gitignored, so never commit the key.

```bash
BACKED_API_KEY=<your-api-key>
```

Tickers must be letters and numbers only (e.g. `OURAx`). As with public assets, only deployments with `supportsAtomicSwaps: true` on a supported network are included.

To make a pre-IPO token part of every run without passing its ticker, add it to the `PRESEEDED_ASSETS` array in `update-tokenlist.js`. That array holds entries in the API's own format. Tokens are deduplicated on chain ID plus address, so a ticker or seed that the public API also returns is not listed twice. Remove the seed once the IPO is live.

The script will:

- Validate the token list against the Uniswap schema
- Auto-generate `logoURI` and `tags` if not provided
- Calculate semantic version bump based on changes
- Update `CHANGELOG.md` with a summary of changes
- Update token statistics in `README.md`

### Semantic Versioning

Following the [Token Lists specification](https://github.com/Uniswap/token-lists#semantic-versioning):

- **Major**: Tokens removed
- **Minor**: Tokens added
- **Patch**: Token details modified (name, symbol, logo, decimals)
